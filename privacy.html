Valtes Ads Reporting

プライバシーポリシー

制定日: 2026年11月10日

1. 対象

このポリシーは、バルテス株式会社（以下「当社」）が運用する社内ツール「Valtes Ads Reporting」（以下「本ツール」）が、Google のアカウントと Google 広告 API から得る情報の扱いを定めます。

2. 取得する情報

  • Google 広告 API へのアクセスを許可するための OAuth のトークン（スコープは Google 広告 API の https://www.googleapis.com/auth/adwords だけ）
  • 当社が所有する Google 広告アカウントの実績（キャンペーン・キーワード別の費用、表示回数、クリック、コンバージョン等）

Gmail、連絡先、カレンダー、ドライブなど、Google 広告以外の情報は取得しません。

3. 使い方

取得した情報は、当社のマーケティング施策の効果の分析と、予算配分の検討だけに使います。

4. 第三者への提供

取得した情報を、販売・貸与・第三者への提供はしません。広告の配信や個人の特定には使いません。

5. 保管

トークンと取得した実績は、当社の管理する端末と社内の保管場所にだけ置き、アクセスできる人を当社の担当者に限ります。

6. Google API Services User Data Policy

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

7. アクセスの取り消し

Google アカウントのサードパーティのアクセスから、本ツールへの許可をいつでも取り消せます。

8. 変更

当社は、必要に応じてこのポリシーを変更することがあります。変更後のポリシーは、このページに掲載した時点から適用します。
