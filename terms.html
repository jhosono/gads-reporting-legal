Valtes Ads Reporting

利用規約

制定日: 2026年11月10日

1. 対象

この規約は、バルテス株式会社（以下「当社」）が運用する社内ツール「Valtes Ads Reporting」（以下「本ツール」）の利用に適用します。

2. 利用できる人

本ツールを利用できるのは、当社が認めた当社の担当者だけです。社外の方への提供はしません。

3. 本ツールでできること

本ツールは、当社が所有する Google 広告アカウントの実績を、Google 広告 API で読み取ります。広告・予算・入札・キャンペーンの作成や変更はしません。

4. 利用者が守ること

  • 当社が所有し、閲覧の権限を持つ Google 広告アカウントだけを対象にすること
  • 認証情報（トークン等）を第三者に渡さず、当社が定めた場所だけに保管すること
  • Google の利用規約と Google API Services User Data Policy に従うこと

5. 免責

本ツールは社内の分析のために提供するもので、取得した数値の正確さや、Google 広告 API が常に使えることを保証しません。

6. 変更

当社は、必要に応じてこの規約を変更することがあります。変更後の規約は、このページに掲載した時点から適用します。
